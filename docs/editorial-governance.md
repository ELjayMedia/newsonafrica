## 2. Authority limits

### Editor-in-Chief
- Final approval on all published content
- Issue and revoke press credentials
- Sign accreditation applications and assignment letters
- Authorize event-specific media access requests
- Approve editorial budget and resource allocation

### Eswatini News Editor
- Commission stories and approve assignments
- Review and approve content for publication
- Issue assignment letters for routine coverage
- Manage day-to-day editorial operations

### Alternate Signatory
- Exercise Editor-in-Chief authority during absence
- Sign assignment letters and accreditation documents
- Cannot revoke credentials without Editor-in-Chief confirmation

## 4. Assignment letter controls

- All assignment letters are numbered sequentially (NOA-ASSIGN-NNN)
- Letters are logged in the assignment register before issuance
- Each letter is signed by an authorized editor
- Copies are retained for [RETENTION PERIOD]
- Expired letters are marked as such in the register
