## Personnel accreditation pack checklist

For each journalist/editorial crew member, the following documents must be collected and verified:

### Identity documents
- [ ] Valid national ID or passport copy (certified)
- [ ] Passport-sized photograph (print + digital, white background)
- [ ] Proof of address (if required by accreditation authority)

### Professional documents
- [ ] Appointment/engagement letter (signed by Editor-in-Chief)
- [ ] Role description and authority limits
- [ ] Short professional biography (150-200 words)
- [ ] Relevant work samples (3-5 published pieces)
- [ ] NOA press credential details (number, issue date, expiry)

### Administrative
- [ ] Consent form for document storage and submission
- [ ] Emergency contact / next-of-kin (if operationally required)
- [ ] Data protection acknowledgment

### Verification
- [ ] All documents match the name used in assignment letters
- [ ] Passport/ID expiry is at least 6 months from application date
- [ ] Press credential is current and verifiable
- [ ] Documents are legible and current
